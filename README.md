# AdmitWise AI

AdmitWise AI is a knowledge-based admission and career guidance system built around transparent, inspectable rules. It combines a React/TypeScript interface with a FastAPI backend, PostgreSQL, and an optional Neo4j knowledge graph.

All seeded universities, programmes and criteria are explicitly demo data. They are not verified admissions facts.

See `docs/ARCHITECTURE.md`, `docs/DATABASE.md`, `docs/KNOWLEDGE.md`, `docs/API.md`, and `docs/SETUP.md` for implementation details.
